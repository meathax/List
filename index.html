What this is

A comparison of the arcade machines MAME emulates with the ROM sets MiSTer FPGA cores can load, to show what is still missing on MiSTer. Everything on this page is computed by a Python script (source) and served as static files.

Enhanced fork additions

This modified view keeps the upstream client interface and adds visual screenshots, YouTube longplay searches, per-game favourites, PCB/driver shortcuts, curated game ranking, nostalgia ranking, and an estimated reusable open-FPGA-code score.

Open-source % caveat: it is a prioritisation estimate of reusable FPGA/MiSTer donor HDL by hardware family; it is not measured source-line coverage and MAME software emulation alone does not count as HDL coverage.
